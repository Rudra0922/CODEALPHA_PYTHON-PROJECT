# Task 2 - Stock Portfolio Tracker

## Description
This is a simple Python-based Stock Portfolio Tracker.
It allows the user to enter stock names and quantities, calculates the total investment value, and displays a portfolio summary.

## Features
- Enter multiple stock names
- Enter the quantity of each stock
- Check stock prices
- Calculate the total value of the portfolio
- Display a portfolio summary

## Technologies Used
- Python 3
- Dictionaries
- Loops
- Conditional Statements
- User Input

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Navigate to the Task 2 folder.
4. Run the Python file using:

```bash
python stock_portfolio.py
